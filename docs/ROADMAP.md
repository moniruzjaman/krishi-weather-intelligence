# Roadmap

## v0.1

- Standalone TypeScript core
- Open-Meteo provider
- Existing agricultural engines extracted
- Stable facade
- Application-independent contracts

## v0.2

- Per-index provenance and confidence
- Explicit operation-window APIs (`spray`, `irrigation`, `fertilizer`, `harvest`)
- Better timezone handling
- Provider response validation
- Retry/timeout policy
- Unit metadata

## v0.3

- Provider registry
- Cache interface
- BMD/provider adapter
- Bangladesh administrative and AEZ context
- Weather alert/event model

## v1.0

- Versioned API contract
- Central KWI API service
- Authentication and rate limits
- Observability
- Offline snapshot support
- Production validation of agricultural models
